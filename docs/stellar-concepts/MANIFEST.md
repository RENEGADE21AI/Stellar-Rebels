# Stellar Rebels screen concept manifest

The `390x844` and `320x568` folders contain individual portrait targets. The contact sheets show the full flows. Each frame combines a generated visual study with deterministic type, panels and controls. Concept artwork describes intended composition. Only captures from the executable build can document shipped gameplay.
